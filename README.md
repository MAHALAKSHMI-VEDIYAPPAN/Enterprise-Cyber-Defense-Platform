# 🛡 Enterprise Cyber Defense Platform

A web-based Enterprise Cyber Defense Platform developed using **Python**, **Flask**, and modern cybersecurity tools.

---

## 📌 Overview

The Enterprise Cyber Defense Platform helps security analysts monitor, analyze, and manage cybersecurity operations from a single dashboard.

It integrates vulnerability scanning, threat intelligence, CVE lookup, incident management, and asset inventory into one platform.

---

## 🚀 Features

- 🔐 User Authentication
- 📊 SOC Dashboard
- 💻 Asset Inventory
- 🔍 Vulnerability Scanner (Nmap)
- 🌍 Threat Intelligence (VirusTotal)
- 🐞 CVE Intelligence (NVD)
- 🚨 Incident Response
- 🔒 Secure API Key Management (.env)
